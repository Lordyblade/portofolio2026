WEBSITE PORTOFOLIO PERSONAL - Ibrahim Mousa

A. Deskripsi Singkat
Website portofolio multi-halaman yang dirancang untuk menampilkan profil 
profesional saya. Website ini terdiri dari halaman utama, tentang saya, 
galeri proyek, dan halaman kontak yang terpisah untuk navigasi yang lebih jelas.
Website ini dibangun dengan desain responsif 
(mobile-friendly) dan modern.

B. Fitur Utama
1. Multi-Page Navigation: Navigasi antar halaman (Beranda, About, Portofolio, Kontak).
2. Responsif: Tampilan menyesuaikan layar (HP/Laptop) menggunakan Bootstrap 5.
3. Galeri Proyek: Halaman khusus untuk menampilkan detail karya.
4. Contact Form: Formulir kontak dengan validasi input.
5. Custom Styling: Desain unik menggunakan CSS sendiri.

C. Teknologi yang Digunakan
1. HTML - Struktur konten.
2. CSS - Styling tambahan dan kustomisasi.
3. Bootstrap 5.3 - Framework CSS utama untuk layout responsif.
4. Bootstrap Icons - Ikon sosial media dan UI.
5. JavaScript - Logika validasi form.

E. Cara Menjalankannya
1. Pastikan semua file (html, css) dan folder 'images' berada dalam satu folder.
2. Buka file "index.html" untuk memulai dari halaman depan.
3. Gunakan menu navigasi (Navbar) untuk berpindah ke halaman lain

F. Catatan
